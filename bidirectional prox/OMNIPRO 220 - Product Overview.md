## Product Description
Multiprocess welding system supporting MIG, TIG, and Stick welding processes.

## Key Features
- 120V/240V dual voltage input
- MIG, TIG, and Stick welding capabilities
- Multiprocess system
- Spool gun ready (optional Spool Gun sold separately)

## Package Contents
- Welder unit
- MIG Gun / Spool gun compartment
- Storage for accessories
- Positive and negative sockets
- Wire feed mechanism
- Controls and displays

## Safety Classification
- **Input Voltage:** 120 VAC / 60 Hz or 240 VAC / 60 Hz
- **Type:** Multiprocess welding system
- **Materials:** Mild Steel, Stainless Steel, Aluminum (with optional Spool Gun)
